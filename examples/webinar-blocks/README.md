# Example: Webinar Blocks (dogfood run, 2026-08-14)

Raw output of the first dogfood run of the v2 bootstrap prompt, unedited and unreviewed. The project is a single-page tool that holds one canonical info block per webinar and generates the per-channel promo blocks from it.

Provenance: the run was executed by an AI agent simulating the project owner's answers from his working profile, not a live interview. Treat it as raw material for a future examples/ directory, not as a finished example. The frictions the run surfaced are issues #1 through #11, labeled `inbox`.

Only the files the bootstrap filled in are included. The fixed docs (agent-rules, exploration, system-map, AGENTS.md, copilot-instructions) are identical to the kit's and are omitted.
