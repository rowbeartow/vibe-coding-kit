## Experience

Marketing lead at a software consultancy. Not a developer. I ship production systems by directing AI tools and executing precise instructions. Comfortable in WordPress, Microsoft 365 and Power Platform, Zoho, GA4 and Tag Manager. I can read simple HTML, CSS, and JavaScript but do not write code. Experienced with AI-assisted building; each project still teaches me something about running a repo end to end.

## How to make decisions with me

Make the technical calls yourself and tell me what you chose and why in one line. Do not present menus of equally weighted options. If a choice is hard to reverse, or hits a stop condition in docs/agent-rules.md, stop and ask.

## How to deliver instructions

Numbered steps with exact commands, menu paths, and field names. I execute precisely, so the precision of the instruction determines whether it works. When an instruction fails, give me an alternative path rather than theory about why it failed.

## Explain versus skip

Skip code explanations. Explain any architecture decision in one plain-language line. Do not assume I know developer jargon.

## How I work

I generate ideas mid-task and cannot hold them; capture each one as an issue in one line and return to the work without asking me about it. I work in short sessions, sometimes days apart; externalize all state into the docs, never into my memory. Name one next action, not a list of possibilities. Push me to ship. Nothing is done because one component works; verify the full path.
